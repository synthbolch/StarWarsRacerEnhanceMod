The "Dead Simple 2026" guide and its all-in-one fix pack include an
already-patched SWEP1RCR.EXE produced with swe1r-patcher, together with its
font artwork (textures/font*.data).

swe1r-patcher's license does NOT permit redistribution:

    No commercial use allowed; all rights reserved.
    You are only allowed to download, compile and run this software.
    Further distribution is not allowed.
    The code which is patched into the output file is licensed under the
    same conditions.
    Therefore, you have no right to redistribute the software's output.

Because of this, this package does NOT contain the patched SWEP1RCR.EXE, the
swe1r-patcher dinput.dll, or its font*.data artwork.

The package therefore uses the community mod's own dinput.dll (AGPL-3.0, see
SW_RACER_RE-AGPL-3.0.txt), which does not require patching the executable and
is recommended anyway.

If you still want the swe1r-patcher fixes (higher-resolution fonts, upgraded
podracers in multiplayer, extra debug features, ...), download it from the
project above and apply it to YOUR OWN copy of the game. Its bundled font
artwork is licensed CC BY-NC 4.0, (c) 2018 Jordan Blackburn:

    https://creativecommons.org/licenses/by-nc/4.0/
