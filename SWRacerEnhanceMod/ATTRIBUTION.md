## 2. AI-generated HD textures (`assets/replacement_textures/`, `optional/hd_8x/`, `optional/ui_hd/`, `optional/ai_textures/`)

These PNG/TGA files were **not** taken from any mod. They were produced locally
from the textures of the game *you* own:

1. In-race textures decoded from `data/lev01/out_textureblock.bin` +
   `out_modelblock.bin` (formats reverse-engineered with the OpenSWE1R community
   tools — see §3), and menu `.TGA`s from `data/images/`.
2. Upscaled 4× with **Real-ESRGAN** (RealESRGAN_x4plus model).
3. The optional **8×** pack (`optional/hd_8x/`) is a *second* Real-ESRGAN x4plus
   pass over the 4× images (→16×), Lanczos-downscaled to 8×, with hard alpha
   re-binarized. Same derivative status as the 4× pack.
4. The optional **AI-regenerated** packs (`optional/ai_textures/realistic/` and
   `optional/ai_textures/clonewars/`) are **newly generated** images: SDXL-Lightning
   (8-step) img2img guided by ControlNet-Tile, prompted from each texture's internal
   name, rendered at 1024px and downscaled to 4×, with the original alpha re-applied.
5. Quality-reviewed with a local vision LLM via **Ollama**.

Tools used to *build* the pack (not distributed in it):

| Tool | Author | Link | License |
|---|---|---|---|
| Real-ESRGAN (code + x4plus weights) | Xintao Wang et al. | https://github.com/xinntao/Real-ESRGAN | **BSD-3-Clause** |
| SDXL-Lightning (8-step UNet) | ByteDance | https://huggingface.co/ByteDance/SDXL-Lightning | **OpenRAIL++** (CreativeML Open RAIL++-M) |
| controlnet-tile-sdxl-1.0 | xinsir | https://huggingface.co/xinsir/controlnet-tile-sdxl-1.0 | **Apache-2.0** |
| Ollama | Ollama Inc. | https://ollama.com | MIT |
| `qwen3.5:9b` / `gemma3:4b` (QA review only) | Qwen/Alibaba, Google | https://ollama.com/library | model license as published |

Because the inputs are the game's own textures, the generated textures are a
**derivative work of the game** and are covered by the disclaimer in §5. The
AI-regenerated images additionally inherit the OpenRAIL++ terms of SDXL-Lightning
(use restrictions apply; see the model card).
